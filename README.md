# SideStage

SideStage is a Chrome extension for managing a karaoke queue from a side panel.
Play YouTube links or local audio/video files on a second screen, assign singer
names, and keep music or images playing between songs.

Designed around a macOS computer and a second display. Other Chrome desktop
environments may work but are not verified.

## Get started

[Install SideStage](docs/user-guide.md#install), then follow the
[illustrated user guide](docs/user-guide.md) to add songs, manage the queue,
set up your screen, and configure breaks.

## Development

See the [development guide](docs/development.md) for build commands, project
structure, storage, and permissions.

## Privacy and support

SideStage has no servers, accounts, or analytics. See the
[privacy policy](PRIVACY.md) for details. Report bugs or ask questions in
[GitHub issues](https://github.com/ChiChou/sidestage/issues).
